# 삼국주방 기획 (1차)

삼국지연의를 기반으로 하는 픽셀 요리 게임. 1인 개발.

## 1. 기획 원칙

| # | 원칙 | 정리 |
|---|------|------|
| 1 | 가볍게 | 1인 개발. 실행 시 외부 라이브러리 0개 (TypeScript + Canvas). 엔진 도입은 필요해질 때만 |
| 2 | 픽셀 기반 | 이미지 생성(AI)은 쓰지 않는다. 무료 에셋 사이트를 참고하고, 직접 찍어야 하면 도트 도구를 쓴다 |
| 3 | 도트 제작 | jpg → 도트 변환 도구로 밑그림, 도트 에디터로 다듬기. 기존 도구로 충분하면 직접 개발하지 않는다 |
| 4 | 손님 | 삼국지연의 등장인물. 이스터에그 손님을 둔다 |
| 5 | 요리 게임 구성 | 주문 → 조리 → 서빙 → 평가의 기본 루프 |
| 6 | 연표와 대사 | 원작 연표 순서대로 손님이 등장하고, 연의 속 관계를 보여주는 대사를 한다 |

## 2. 현재 상태 (v0.1)

- 1~5장 플레이 가능 (원작 제1·3·5·8·21회)
- 레시피 4종, 재료 8종, 손님 인내심·속도 보너스·별점·해금·저장
- 숨은 손님 1명 (3장 허소: 실수 없이 진행 시 등장)
- 픽셀 아트는 코드로 그림 (`src/game/sprites.ts`)
- 원작 120회 데이터: `src/data/chapters.json` 외

- 코에이 삼국지 등 기존 게임의 캐릭터 디자인은 저작권 대상. 참고해서 따라 그리지 않는다. 원작 소설(나관중, 모종강본)은 퍼블릭 도메인
- 외부 에셋을 쓰면 `public/assets/CREDITS.md`에 출처·라이선스를 적는다

| 도구 | 용도 | 비용·라이선스 |

직접 개발은 보류. 필요해지면 `scripts/`에 변환 스크립트(다운샘플 → 팔레트 양자화 → 투명 처리)를 만든다.

## 4. 게임 구성

### 핵심 루프 (구현됨)

1. 손님 등장 (최대 3석, 인내심 게이지)
2. 주문: 요리 이름 + 대사
3. 조리: 재료를 순서대로 냄비에
4. 서빙: 맞으면 점수 + 속도 보너스, 틀리면 감점·인내심 감소
5. 평가: 장 종료 시 별 0~3개, 절반 이상 대접하면 다음 장 해금

### 추가할 것

| 우선순위 | 항목 | 내용 |
|----------|------|------|
| 1 | 관계 대사 | 같은 장에 관계 있는 인물이 앉으면 특별 대사 (아래 5절) |
| 2 | 장 사이 이야기 | 장 시작 전 원작 상황을 2~3줄 대화로 보여주기 |
| 3 | 정산과 업그레이드 | 번 돈으로 재료 칸 추가, 인내심 보너스, 조리 도구 |
| 4 | 새 레시피 | `chapters.json`의 `foodHooks` 기반 (온주참화웅, 계륵, 만두, 칠보시 등) |
| 5 | 그래픽 교체 | 코드 그림 → PNG 스프라이트 (위 도구), 갈무리 폰트 |

## 5. 손님·연표·관계 대사

- 장 = 원작 회차 하나. `stages.json`의 `chapter`가 `chapters.json`을 가리킨다
- 손님은 그 회차의 `cast`에서 고른다 → 연표 순서가 자동으로 지켜진다
- 원작 8개 구간(`arcs.json`)을 업데이트 단위로 삼고, 구간마다 보스 손님 1명

### 관계 대사 데이터 (제안)

`src/data/relations.json`

```json
[
  {
    "pair": ["lubu", "dongzhuo"],
    "from": 3, "to": 9,
    "kind": "의부자",
    "lines": {
      "lubu": "의부께서도 와 계셨군요.",
      "dongzhuo": "봉선아, 너도 한 그릇 하거라."
    },
    "after": { "from": 9, "lines": { "lubu": "그 늙은이 얘기는 꺼내지 마라." } }
  }
]
```

- `from`/`to`: 관계가 유효한 원작 회차 범위 (관계는 연표에 따라 변한다: 여포·동탁은 의부자 → 원수)
- 손님이 앉을 때 같은 장에 상대가 있으면 일반 대사 대신 관계 대사

### 이스터에그 후보

| 손님 | 조건 | 원작 근거 |
|------|------|-----------|
| 허소 (구현됨) | 3장 무실수 | 제1회 조조 인물평 |
| 화타 | 손님이 화난 상태로 3번 이상 | 의원 |
| 좌자 | 귤 레시피 완성 | 제68회 귤 껍질 일화 |
| 관로 | 특정 장을 별 3개로 | 제69회 점쟁이 |

## 7. 데이터 수집

### 출처와 수집 방법

| 데이터 | 출처 | 방법 |
|--------|------|------|
| 120회 회목 (`chapters.json`의 `title`) | 모종강본 목차 ([豆瓣读书](https://book.douban.com/subject/37200502/)) | 웹 검색 → 목차 페이지 가져오기 → 이체자를 표준 번체로 정리 |
| 회목 교차 확인 | [番茄小说 목차](https://fanqienovel.com/keyword/1780947222) | 1~46회, 120회 대조 |
| 배경 연도, 등장인물, 음식 장면, 한글 이름 | 원작 내용 기반 수작업 | 검토 필요 |
| 인물 한자·세력 | 수작업 | 세력은 '대표 진영' 기준 |

### 사용한 검색 쿼리

```
三國演義 回目 一百二十回 全目錄
```

목차 페이지에 보낸 요청: "第一回부터 第一百二十回까지의 회목을 빠짐없이 '번호 | 회목' 형식으로 나열"

### 판본 차이

판본마다 회목 글자가 조금씩 다르다. 현재는 모종강본 기준:

- 제9회: 除暴凶 / 除兇暴
- 제12회: 大戰呂布 / 大破呂布
- 제26회: 損兵折將 / 敗兵折將

### 검증

- `npm run validate`: 120회 연속성, 인물·레시피 참조, 구간 범위, 장 연도와 원작 연도 일치
- 원작 서술 순서가 연대순과 다른 곳은 경고로만 표시 (예: 제15회 195년 < 제14회 196년)
