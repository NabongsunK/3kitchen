# 삼국주방 (三國廚房)

삼국지연의를 기반으로 한 픽셀 요리 게임입니다.

## 게임 소개

- 삼국지연의 120회의 손님들에게 요리를 서빙합니다
- 현재 제1~5장(원작 제1회 도원결의 ~ 제21회 청매자주론영웅)을 플레이할 수 있습니다
- 손님의 주문에 맞는 재료를 순서대로 냄비에 넣고 서빙하세요
- 손님의 인내심이 다하기 전에 정확한 레시피로 대접하면 점수를 얻습니다. 빨리 낼수록 보너스가 붙습니다
- 손님 절반 이상을 대접하면 다음 장이 열립니다. 모두 실수 없이 대접하면 별 3개

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 으로 접속합니다.

| 명령 | 설명 |
|------|------|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 후 `dist/`로 빌드 |
| `npm test` | 게임 로직 단위 테스트 |
| `npm run validate` | 콘텐츠 데이터 무결성 검사 (Python 3) |

## 조작

| 키 | 동작 |
|----|------|
| 1 ~ 8 | 재료 넣기 |
| Enter / Space | 선택한 손님에게 서빙 |
| ← → / Tab | 손님 선택 |
| Backspace / X | 냄비 비우기 |
| R | 레시피 보기 |
| Esc | 멈춤 |

마우스나 터치로 재료 칸, 손님, 버튼을 눌러도 됩니다.

## 레시피

| 요리 | 재료 (순서대로) |
|------|----------------|
| 콩죽 | 콩 → 쌀 |
| 도원복숭아주 | 복숭아 → 술 → 꿀 |
| 청매절임 | 매실 → 소금 → 꿀 |
| 화로꼬치 | 고기 → 술 → 소금 |

## 콘텐츠 데이터

`src/data/`의 JSON 파일이 곧 테이블입니다 (나중에 RDB로 옮길 것을 전제로 한 구조). 파일 이름이 테이블 이름이고, 기본키는 `테이블약자ID` (값은 `chr0001`처럼 약자 + 4자리 순번)입니다. 테이블 목록과 열 정의는 [docs/데이터.md](docs/데이터.md)에 있습니다.

| 테이블 | 내용 |
|--------|------|
| `chapters`, `chapter_casts`, `chapter_food_hooks` | 원작 120회: 회목(모종강본), 배경 연도, 주요 인물, 음식 장면 |
| `characters`, `factions` | 인물 120명과 세력 |
| `arcs` | 업데이트 단위 8개 구간과 구간 보스 손님 |
| `stages`, `stage_customers` | 게임 장: 무대가 되는 원작 회차, 손님 순서, 대사, 난이도 |
| `recipes`, `recipe_ingredients`, `ingredients` | 레시피와 재료 |

`chapter_food_hooks`에는 원작 속 음식·술·연회 장면(온주참화웅, 청매자주, 계륵, 칠보시, 만두의 유래 등)을 모아 두었습니다. 데이터를 고친 뒤에는 `npm run validate`로 검사합니다.

## 구조

```
src/
  main.ts          캔버스 크기 조정, 입력, 게임 루프
  game/app.ts      화면(타이틀·장 선택·소개·영업·결과) 그리기와 입력 처리
  game/play.ts     영업 규칙 (DOM과 무관한 순수 로직)
  game/save.ts     진행도 저장 (localStorage)
  game/sprites.ts  코드로 그리는 픽셀 아트
  data/            콘텐츠 데이터
scripts/validate.py
```
